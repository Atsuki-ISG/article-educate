# 教育記事特有の注意点

公文書との使い分け・引用ルール・プライバシー配慮。

## 公文書との使い分け

| 種類 | 文体 | 目的 |
|---|---|---|
| 公文書（通知、お知らせ） | 「である」調、正式な表現 | 正確な情報伝達 |
| 広報記事 | 「ですます」調、親しみやすい表現 | 理解促進、啓発 |

`.claude/rules/` の執筆ルールは **広報記事** に適用する。

## 引用・参照のルール

### 公的文書の引用

引用後に必ず平易な言い換えを添える。

```
良い例：
令和4年に改訂された「生徒指導提要」では、生徒指導を
「児童生徒が、社会の中で自分らしく生きることができる存在へと、
自発的・主体的に成長や発達する過程を支える教育活動」と定義しています。

少し難しい言葉ですが、つまり
「子どもたちが自分らしく成長できるよう、学校全体で支えていく取り組み」ということです。
```

### 参考文献の記載

記事の最後に記載する。

```
---
**参考文献**
- 文部科学省「生徒指導提要」（令和4年12月改訂）
- 〇〇市教育振興基本計画
```

## プライバシーへの配慮

```
良い例：
- 「ある小学生のお子さん」「中学生のBさん」
- 「保護者の方からこんなご相談がありました」
- 具体的な学校名、地域名は出さない

悪い例：
- 「〇〇小学校の3年生の男の子」
- 「△△地区にお住まいの保護者から」
```

## フィードバック反映のプロセス

1. **記録と分析** — どのような指摘か、影響範囲の確認
2. **記事への反映** — 該当箇所の修正、同様の問題がないか確認
3. **抽象化** — 個別のFBから一般化できる原則を抽出
4. **ルールへの反映** — `.claude/rules/` の該当ファイルを更新
5. **パターン蓄積** — `data/patterns/` に追記
