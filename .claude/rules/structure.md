# 記事構成ルール

教育広報記事の構成・階層・まとめの作り方。

## 全体構成

長い記事は大きな区切りを設ける（「はじめに」「本編」「まとめ」など）。

### セクション冒頭のリード文

各セクションの冒頭には以下を含むリード文を入れる：

1. **なぜその話をするのか** — 読者がそのセクションを読む動機
2. **体験談・エピソード（適度に）** — 現場の経験で親近感を出す
3. **次の展開の予告** — 何を学ぶかを明示

```
良い例：
## 家庭でできる「心の居場所づくり」

学校での取り組みをお伝えしましたが、ここからは「家庭でできること」についてお話しします。
ある保護者の方から「学校でやっていることを、家でもやってみたい」というお声をいただいたことがきっかけです。

ここでは、日常の中で実践できる3つのポイントをご紹介します。
```

**バランス：** すべてのセクションにエピソードは不要。冗長になるなら省く。

### 「ポイント」「コツ」で要点明示

```
### お子さんの話を「聴く」コツ

**ポイント：** アドバイスより先に、まず「そうだったんだね」と受け止める

**コツ1: 手を止めて、目を見る**
**コツ2: 「うん、うん」とうなずく**
**コツ3: 最後まで聞いてから話す**
```

## 具体例の使い方

### エピソードで伝える

```
**【エピソード】ある朝の出来事**

「行ってきます」の声がいつもより小さかったAさん。
お母さんは「どうしたの？」と聞きたい気持ちをぐっとこらえて、
「いってらっしゃい、気をつけてね」と送り出しました。

その日の夕方、Aさんの方から「今日ね、ちょっと嫌なことがあって...」と話し始めたそうです。
```

### 良い例と悪い例の対比（❌/✅）

```
❌ こんな声かけしていませんか？
「なんで言わなかったの？」「早く言ってくれればよかったのに」

✅ こんな声かけに変えてみましょう
「話してくれてありがとう」「それは辛かったね」
```

## 視覚的な整理

- 箇条書き・番号付きリストで情報を整理
- 対比・比較は表形式で
- 太字で重要ポイントを強調

## まとめセクション

### 要点を復習

```
## まとめ

### この記事でお伝えしたこと

**家庭でできること**
- お子さんの話を「聴く」姿勢
- 「そうだったんだね」と受け止める声かけ

**困ったときの相談先**
- 学校（担任、スクールカウンセラー）
- 教育相談窓口
```

### 励ましの言葉で締めくくる

```
子育てに正解はありません。悩むこと、迷うことがあって当然です。
大切なのは、お子さんのことを想う気持ち。その気持ちがあれば、きっと大丈夫です。
困ったときは、一人で抱え込まず、ぜひ私たちにご相談ください。
```

## 執筆プロセス

1. 大まかな目次を作成
2. 各セクションの見出しを決める
3. 各セクションで伝えたいポイントを箇条書き
4. 具体的なエピソードを考える
5. 本文を執筆

## 執筆チェックリスト

### 文体
- [ ] 「ですます」調で統一
- [ ] 読者に語りかける表現
- [ ] 専門用語に説明あり
- [ ] 1文が短く簡潔
- [ ] 保護者を責める表現なし

### 構成
- [ ] 見出しの階層が適切
- [ ] 各セクションに要点明示
- [ ] 良い例/悪い例の対比あり
- [ ] エピソードが豊富
- [ ] まとめセクションあり
- [ ] 相談先が明記

### 表現
- [ ] 励まし・共感の表現あり
- [ ] 疑問形で興味を引いている（語尾は「？」）
- [ ] 箇条書き・表で整理
- [ ] 重要ポイントは太字
- [ ] 否定表現を避けている
- [ ] プライバシー配慮

### 公的機関として
- [ ] 根拠となる資料・指針を引用
- [ ] 参考文献を記載
- [ ] 誤解を招く表現なし
