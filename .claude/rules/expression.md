# 表現の指針

読者との距離感・エピソードの使い方・強調手法。

## 読者との距離を縮める

### エピソードで親近感を出す

**使いどころ：**
- 新しいセクションのリード文
- 重要なポイントの強調
- よくある悩みの説明
- 「本当に効果あるの？」と疑問に思いそうなとき

```
良い例：
「ある保護者の方から「うちの子、最近何も話してくれなくて...」というご相談をいただきました。」
「実は、学校の先生たちも最初から上手にできたわけではありません。」
「「聴く」って簡単そうで難しいですよね。私たちも日々学んでいます。」
```

**注意点：**
- 全セクションにエピソードは不要（冗長になる）
- 簡潔に（2〜3文程度）
- 個人が特定されない配慮
- エピソード→本題への自然な流れ

### 二人称で語りかける

```
良い例：「皆さんのご家庭ではいかがですか？」
悪い例：「保護者は〜すべきである」「各家庭において〜」
```

### 共感と寄り添い

```
「お子さんのこと、心配になりますよね。」（共感）
「どう声をかけたらいいか、迷うことありませんか？」（悩みを代弁）
「うまくいかない日があっても、大丈夫です。」（励まし）
```

## 公的機関としての信頼性

### 根拠を示す

```
「文部科学省の「生徒指導提要」（令和4年改訂）では、〜と示されています。」
「〇〇市の調査によると、〜という結果が出ています。」
```

### 相談先を明記

```
**ご相談はこちらまで**
- 〇〇市教育相談窓口：XXX-XXXX（平日9:00〜17:00）
- 各学校のスクールカウンセラー
- 担任の先生
```

## 段階的な説明

「まず〜」「次に〜」「最後に〜」で順序を明示する。

```
**1. まず、手を止める** — スマホを置いて、お子さんの方を向く
**2. 次に、うなずきながら聴く** — 「うん、うん」「そうなんだ」
**3. 最後に、気持ちを受け止める** — 「それは嫌だったね」「頑張ったんだね」
```

## 強調手法

- **太字** で重要ポイントを強調
- ❌/✅ で対比を視覚化
- 表で情報を比較整理
- 箇条書きで要点を並列

## 記事の開き方パターン（参考記事から抽出）

### パターン1: 読者の悩みから入る
読者が「自分のことだ」と感じる具体的な場面を描写してから本題に入る。

### パターン2: 問いかけから入る
「〜って何？」「〜していませんか？」で読者の興味を引く。

### パターン3: エピソードから入る
ある保護者の声や、学校での出来事から書き始め、本題につなげる。

## 記事の閉じ方パターン

### パターン1: 要点整理 + 励まし
まとめで要点を復習し、最後に「大丈夫です」で安心感を与える。

### パターン2: 次のアクション提示
「まずは1つだけ、試してみてください」で具体的な一歩を促す。

### パターン3: 相談への橋渡し
「困ったときはいつでもご相談ください」で支援の入口を示す。
