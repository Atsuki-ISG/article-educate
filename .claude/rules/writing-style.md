# 執筆文体ルール

教育広報記事を執筆する際の文体・トーン・用語の指針。

## 基本トーン：親しみやすい「ですます」調

### 推奨される表現

**語りかけるような文体**
- 「〜してみてください」「〜しましょう」で読者を導く
- 「〜んです」「〜なんです」で親近感を出す
- 「〜でしょうか？」で読者に問いかける

```
良い例：
「お子さんの様子、気になることはありませんか？」
「これが大切なポイントなのですが、**子どもの話を「聴く」ことが、信頼関係の第一歩**なんです。」
「最初から完璧じゃなくても大丈夫です。」
```

**励ましと共感の表現**
- 「大丈夫です」「心配ありません」
- 「一緒に考えていきましょう」
- 「少しずつ〜していけば大丈夫です」
- 「悩んでいるのは、お子さんのことを大切に思っているからこそです」

**口語的な表現の活用**
- 「〜ってなんだろう？」「〜って何？」
- 「〜じゃありません」「〜じゃなく」
- 「ぐっと」「ちょっと」「とても」などの副詞
- 「ふんわり」「ざっくり」などの柔らかい表現

### 避けるべき表現

**硬い・堅苦しい表現**
- 「〜である」「〜だ」などの断定調
- 「〜すべきである」「〜しなければならない」
- 「本稿では」「以下に示す」などの論文調
- 「〜に関して」「〜について述べる」などの形式的な表現
- 「児童生徒」→「子どもたち」「お子さん」に言い換え

**距離を感じさせる表現**
- 三人称での説明（「保護者は〜」ではなく「皆さんは〜」「私たちは〜」）
- 受動態の多用（「〜される」ではなく「〜します」）
- 行政文書のような無機質な表現

## 専門用語の扱い方

### 必ず平易な説明を添える

```
良い例：
「生徒指導提要（学校での子どもへの関わり方をまとめた国の指針）」
「自己肯定感（自分のことを大切に思える気持ち）」

悪い例：
「生徒指導提要に基づき〜」（説明なし）
「発達支持的生徒指導を推進する」（専門用語のみ）
```

### 日本語の平易な言葉を優先

- 「居場所づくり」（心理的安全性の確保）
- 「話を聴く」（傾聴）
- 「心の回復力（レジリエンス）」
- 「自分で決める力（自己決定能力）」

## 文章の長さとリズム

- 1文は2〜3行以内が目安
- 複雑な内容は箇条書きに分解
- 長い説明は段落を分ける

### 疑問文の語尾は必ず「？」

```
良い例：「お子さんの様子、最近どうですか？」
悪い例：「お子さんの様子はいかがでしょうか。」（疑問文なのに「。」）
```

## 否定的な表現を避ける

| 避ける表現 | 言い換え |
|---|---|
| 「これでは子どもは話してくれません」 | 「こう声をかけると、話しやすくなります」 |
| 「子どもの気持ちを理解するのは難しいです」 | 「子どもの気持ち、一緒に考えてみましょう」 |
| 「こういう対応は避けてください」 | 「こんな工夫をすると、もっと伝わりやすくなります」 |

**保護者を責めない** — 常にポジティブな言い換えを心がける。

## 絵文字は使わない

親しみやすさは文体で表現する。
```
悪い例：「一緒に頑張りましょう！💪」
良い例：「一緒に、少しずつ取り組んでいきましょう。」
```
