## AI声優オーディション会場

本記事では、AI声優オーディションの会場の様子、要するに **私の声がいかにして決まったか** 、その様子を解説していきます。

弊チャンネルをご覧の方はご存知の通り、私の動画では合成音声を使ってナレーションをしています。

[**VOICEPEAK 宮舞モカ** *『VOICEPEAK 宮舞モカ』は、声優「峯田茉優」の声を元に制作した、ブレス感のある落ち着いたかわいらしい声が特徴の入力* *www.ah-soft.com*](https://www.ah-soft.com/voice/moca/)

VOICEPEAKさんを利用させていただいてます

しかし、合成音声の種類はとても多く、初めて選ぶ方は何を基準に選んだらよいのか迷うかもしれません。

そこで、本記事では **合成音声の選び方** という実践的な話を前半にしつつ、後半では声の聞き比べ、すなわち **AI声優オーディション** の様子をお届けしていきます。

この" **オーディション** "というのはふざけた比喩ではなく、いろんな音声を聞き比べて、「これかな、いややっぱあっちかな〜」みたいに考えていると、もうこれは「オーディション」としか形容できないような仕事になってきます。  
本業でこれをしていた時は「仕事中にこんなことしていていいのかな…いやこれが仕事か。」みたいな気持ちになっていました。

そんなプロセスの面白みも一緒にお伝えしていこうと思うので、ぜひ楽しんでいただけると嬉しいです。

## 候補者

最初に重要なのは、どんな候補者がいるかを知ることです。  
現代の環境における主要なAI声優たちをご紹介します。

### VOICEPEAK

最初に紹介するのは、私の音声となったVOICEPEAKさんです。VOICEPEAKさんはプロの声優さんに協力いただいて、細やかな感情設定などができる高品質な合成音声を作っているソフトメーカーです。

ソフトは買い切りで1万円(商用ライセンスは+5万円)と、他の選択肢と比べたときにちょっと高く感じるかもしれないのですが、後述する「声優さんが明記されている」安心感と、かつ声自体の品質の高さから推したい合成音声メーカーさんです。

[**VOICEPEAK 宮舞モカ** *『VOICEPEAK 宮舞モカ』は、声優「峯田茉優」の声を元に制作した、ブレス感のある落ち着いたかわいらしい声が特徴の入力* *www.ah-soft.com*](https://www.ah-soft.com/voice/moca/)

このラインより上のエリアが無料で表示されます。

### VOICEVOX

VOICEVOXは無料で使える日本製の音声合成ソフトです。商用利用も可能で、キャラクターごとに異なる声が用意されており、特にずんだもんやめたんなど、独特なキャラクターたちが人気です。多分皆さんもYouTubeで見かけたことがあるのではないでしょうか。

無料でありながら十分に品質も高く(公式では"中品質"というワードを使ってます)、感情表現や抑揚の調整もできるため、YouTuberを中心に広く使われています。ただし、権利関係については各キャラクターごとに利用規約が異なるため、使用前に必ず確認が必要です。

正直この品質のソフトが無料で使えるのおかしいレベルなので、最初にこちらで検討して、VOICEVOXでは満たせない強い理由がある場合に他の選択肢を検討する、という流れが良いと思います。

[**VOICEVOX | 無料のテキスト読み上げ・歌声合成ソフトウェア** *無料で使える中品質なテキスト読み上げ・歌声合成ソフトウェア。商用・非商用問わず無料で、誰でも簡単にお使いいただけます。イン* *voicevox.hiroshiba.jp*](https://voicevox.hiroshiba.jp/)

### ElevenLabs

ElevenLabsは英語圏で非常に人気の高い音声合成サービスです。感情表現が豊かで、多言語に対応しており、日本語も使えます。Voice Cloning機能も優秀で、少量のサンプル音声から声を再現できます。無料プランもありますが、月額課金制で、本格的に使うとなるとそれなりにコストがかかります。

[**Free AI Voice Generator & Voice Agents Platform | ElevenLabs** *Create lifelike speech with our AI voice generator and voice* *elevenlabs.io*](https://elevenlabs.io/)

ただ、公式が用意しているモデルは英語っぽい発音になりがちで、完全にネイティブな日本語話者の声というよりは、流暢に日本語を話す外国人という印象を受けることもあります。(海外製のサービスは基本この問題が出てきます。)

ただ、ElevenLabsは「自分の声のモデルを投稿して収益化できる」という機能があるため、最近は自然なモデルも増えてきています(もはや"自然"というか"リアル"過ぎて、解説動画とかゲームとかには相応しくない気がしますが)。  
試しにこちらの日本語フィルターした検索結果から色々聞き比べてみてください。

### OpenAI Text-to-speech

OpenAIが提供する音声合成APIです。ChatGPTで有名なOpenAIらしく、自然な音声が生成でき、複数の声のバリエーションが用意されています。APIベースなので開発者向けではありますが、料金は従量課金で比較的リーズナブルです。速度も速く、自動化との相性も良いのですが、こちらも英語っぽい発音になる傾向があり、完全に日本人の声という感じではありません。

[https://platform.openai.com/docs/guides/text-to-speech](https://platform.openai.com/docs/guides/text-to-speech)

### Google Text-to-Speech AI

Googleが提供する音声合成サービスです。Google Cloud Platformの一部として提供されており、多言語対応で日本語も含まれています。料金は文字数ベースの従量課金ですが、無料枠もあるため、少量の利用であれば無料で使えます。ただし、こちらもOpenAI同様、英語っぽい発音傾向を感じます。

### 開発者向け枠

### Style-Bert-VITS2

Style-Bert-VITS2は、日本語に特化したオープンソースの音声合成モデルです。非常に感情豊かな音声を生成できます。完全にローカルで動作させることができるため、プライバシーやコストの面でメリットがあります。ただし、環境構築やモデルの扱いには技術的な知識が必要で、開発者でない方には少しハードルが高いかもしれません。

音声データを用意して、下記レポジトリ内のColabというものをポチポチしていけばモデルができあがるようにはなっています。

ちなみに私はこちらを使って同僚と一緒に自分たちの声で音声モデルを作ったりしていました。 学習に使う音声データの音質が大事だったりするので、ちょっと高めのマイクとかも用意して録音などを行っていました。めっちゃ楽しかったです。

### Cartesia

Cartesiaは、リアルタイム音声生成に強みを持つAPIサービスです。速度が非常に速く、ストリーミング生成にも対応しているため、ライブ配信やリアルタイムアプリケーションに最適です。Voice Cloning機能(声を真似たモデルを作る機能)も優秀で、短い音声サンプルから声を再現できます。料金は従量課金制で、速度を重視するなら有力な選択肢です。

先ほどお話しした通り、Voice Cloningの機能がとても簡単に試せるので、ぜひ一度試してみてください。社内での身内ウケとかを狙えます。

他にも選択肢はいろいろあるのですが、現状使えそうなのはこの辺りかな〜というのを挙げていきました。 次に、どうやって選んでいくかの基準についてお話ししていきます。

## 最初に確認すること: 学習元が明記されているか

合成音声に関しては、残念なことながら国内で権利に関する問題が相次いでいます。  
無料で高品質な音声AIが使えるソフトとして注目を集めた AivisSpeech では、無断で声優さんの声をモデル化し、広く配布したことで炎上しました。

[**声優・山村響さんの声、無許可でAIモデル化　AivisSpeech「Anneli」問題が波紋** *AI音声合成ソフト「AivisSpeech」の標準モデル「Anneli」が、声優・山村響さんの音声を無許可で使用して作られ* *ascii.jp*](https://ascii.jp/elem/000/004/318/4318182/)

多様な高品質モデルたちで注目を集めたにじボイスも、声優さんたちに声が酷似しているモデルたちがあると問い合わせを受けて、それらのモデルを取り下げています。

[**『にじボイス』一部キャラクターの提供終了に関するお知らせ** *株式会社Algomaticは、AIを活用した音声生成プラットフォーム『にじボイス』の一部キャラクター33体の提供を、202* *algomatic.jp*](https://algomatic.jp/news/notice_nijivoice_20251111)

合成音声を選ぶ立場としては、このように問題を元に提供中止となると、途中で声優を変えねばならず、これは大きなリスクと言えるでしょう。  
なので、学習元が明記されているモデル(VOICEPEAK, VOICEVOXなど)に絞るのが賢明ではないかなと考えています。

## まずは機能性で絞る

では、どんな選択肢があるかを知ったところで、オーディションを開催する前にまずは機能性で絞っていきましょう。  
私が気にするのは次の3つの点です。

- 自動化ができるか
- 料金
- 速度

### 自動化ができるか

基本的にはこの記事で挙げたソフトは全て自動化することができます。  
多くのサービスはAPIを提供していて、それを通じて自動化できるのと、VOICEPEAKでは、アプリをインストールした後にそのアプリを使ってコマンドラインで音声の生成コマンドを実行することができます。

参考までに、私は次のような関数を書いて自動で生成するようにしています。

```typescript
export async function generateVoicePeak({
  text,
  narrator = "Miyamai Moca",
  outputFilePath = "./output.wav",
  emotions = defaultEmotions,
  speed = 125,
  pitch
}: VoiceParams): Promise<void> {
  console.log(\`Generating voice for: ${text}\`);

  const voicePeakPath = "/Applications/voicepeak.app/Contents/MacOS/voicepeak";

  const args = [
    "--say",
    text,
    "--narrator",
    narrator,
    "--out",
    outputFilePath,
    "--emotion",
    \`bosoboso=${emotions.bosoboso},doyaru=${emotions.doyaru},honwaka=${emotions.honwaka},angry=${emotions.angry},teary=${emotions.teary}\`
  ];

  if (speed !== undefined) {
    args.push("--speed", speed.toString());
  }

  if (pitch !== undefined) {
    args.push("--pitch", pitch.toString());
  }

  return new Promise((resolve, reject) => {
    const process = spawn(voicePeakPath, args);

    process.on("close", (code, signal) => {
      if (code === 0) {
        console.log("Voice generation completed successfully");
        resolve();
      } else {
        reject(
          new Error(
            \`Voice generation failed with code ${code} and signal ${signal}\`
          )
        );
      }
    });

    process.on("error", (err) => {
      reject(err);
    });
  });
}
```

それ以外のサービスたちは基本的にAPIが存在しているのでそれを叩けばOKです。

ただ、他のサービスを試すとなったときに、ちゃんと自動化の手段があるかどうかは見ておくのが大事です。

これをプログラマブルに実行できるのか、自分で逐一読み上げてもらう文章をコピペして音声ファイルをダウンロードみたいなことをしなければいけないのかでは、生産性にとんでもない差が生まれます。

### 料金体系をチェック

料金もチェックしましょう。多くの企業では従量課金となっていると思います。これはサービスによるのですが、文字数単位であったり、や分数単位での課金がなされています。

ElevenLabsを例にとると、プランごとに月毎の最大読み上げ分数が決まっており、それを超えると秒数に応じた従量課金となります。

![画像](https://assets.st-note.com/img/1763112463-6oq5KMWcBXCGF1DYtIuahn8i.png?width=1200)

https://elevenlabs.io/pricing#pricing-table

ちょっと試すぐらいだったら、従量課金の方が安く済むと思うのですが、私のように最初から「長期でやっていくぞ！」という場合は、VOICEPEAKの買い切りという形態はものすごく安くなると思います。  
多分、私の今までした文字数を考えると、従量課金であれば数十万単位かかっていると思います。

特に自動化して大量にコンテンツを作っていくときには、一度生成したものを読み上げてもらった後に、「やっぱりこういう表現の方がいいな」となって、また生成し直すということが多々発生したり、 またシンプルに書き間違いをすることだってあります。

そうなったときに、お金がかかることを心配すると、妥協してしまったり、ストレスになってしまったり、そうやって創作活動の幅が無意識に狭まってしまう危険性があると感じます。

私の意見としては、長期で運用するつもりがある場合は、無料のもの(VOICEVOX)か買い切りのものがおすすめです。  
ナレーションとかで単発でちょいちょい欲しいものに関しては声質も踏まえて従量課金のサービスが望ましいことが多いでしょう。

### 速度

正直申し上げますと、私は速度をそんなに気にしなかったので、それぞれのサービスの測定結果とかまでは持っていませんが、もしライブ配信のようなユースケースを想定されるのであれば、結構重要な指標かもしれません。

ちなみに私が普段使っているVoiceSpeakは、体感で一つの読み上げを生成するのに1、2秒かかる印象です。  
これはリアルタイムでの配信にはちょっと工夫が必要になってくる秒数かなと思うのですが、それ以外のサービスとかでは1秒切るような速さで生成するものもあります。

また、ストリーミングといって全部のデータが生成されるのを待つのではなく、できた部分からデータを返してもらう、みたいな工夫もできたりするので、そういったものも活用しましょう。

## AI声優オーディションをしよう！

それでは、真面目な話はここまでにしまして、ここからが楽しいところです。  
これまでの基準で絞り込んださまざまなAI声優たちを実際に読み上げてもらうオーディションを開催しましょう！

### オーディションの進め方

それでは、オーディションを進めるにあたっては、まずはキャラ設定、そして読み上げてもらう文章を用意する必要があります。あとキャラのイラストなどもあるのであれば用意しておきましょう。グッとイメージしやすくなります。

例えば、AIでサボろうチャンネルのキャラクターである万象サボルは、大雑把には「クールな解説キャラで感情の起伏が少なめ」という設定です。そして読み上げる文章としては、実際に作る解説動画の台本を作りまして、そちらを読み上げてもらいました。  
納得感を得るために最低でも5パターンぐらいのセリフは用意した方がいいかなと考えています。

### テスト用セリフの選び方

ここで重要なのが、どんなセリフを読み上げてもらうかです。私が意識したポイントは次の通りです。

**バリエーションを持たせる**

単調な説明文だけでなく、疑問形、感嘆、専門用語、数字の読み上げなど、実際の動画で使うであろう多様な表現を含めましょう。例えば私の場合はこんな感じです。  
正直、サボルちゃんは感情の起伏が少なめなので、 **感嘆** とかはあまりいらなかったのですが、キャラによっては非常に大事です。

- 「今回はプロンプトの基礎についてお話しします」（導入の挨拶）
- 「なぜこの手法が優れているのでしょうか？」（疑問形）
- 「精度は実に92.5%に達しました」（数字を含む）
- 「これは驚くべき結果です」（感情を含む）
- 「次回は実装編をお届けします」（締めの挨拶）

また、短い文だけでなく、それなりに長い文章を読み上げてもらうのも大事です。「あ、ここで不自然に区切るんだ」とか「ここの助詞の発音、変だな」みたいな発見があります。

### 聞き比べる

準備が整ったらいよいよ本番です。  
用意したセリフを順々に音声ツールたちに渡していって音声を生成します。

私がサボルちゃんの声を選んだ時のことを振り返っていきますと、最初はVOICEVOXを試しました。  
ずんだもんは…さすがに今回の要件に合う訳はないとして、一番イメージに近いなと感じたのはもち子さんでした。

[**VOICEVOX もち子さん | 無料のテキスト読み上げソフトウェア** *VOICEVOXは「もち子さん」の明瞭で穏やかな声で誰でも簡単に音声を作成できる、無料のテキスト読み上げソフトウェアです。* *voicevox.hiroshiba.jp*](https://voicevox.hiroshiba.jp/product/mochikosan/)

しかしちょっと想定しているよりは元気過ぎると言いますか、しっかりしたお姉さん感が強く今回は断念。  
万人に伝わるか分かりませんが、私がイメージしていたのは長門 有希的なキャラクターで、あまり感情の起伏がない感じで喋ってくれると嬉しいなと思っておりました。

次にElevenLabsを試したのですが、率直な感想としては

**めっちゃ外国人っぽい**

でした。なんというか発話は自然なんですが、喋り方が **母国語が英語の人が流暢に日本語を喋っている** という感覚が抜け切れず、ちょっとキャラクターに対しての採用は難しいかなと感じました。多分ナレーションとかだったら全然ハマると思うんですけど。

これはOpenAIやGeminiなどの海外産モデルたちに基本当てはまる性質です。これら以外にも様々な日本語モデルを試したものの、理想の声は中々見つかりませんでした。

そんな悩んでいたところに知ったのがVOICEPEAKです。こちらのサンプル動画を見て「 **こ、これは…！！！** 」となりました。

![](https://www.youtube.com/watch?v=MQfFxh2JeP8)

VOICEPEAKは買い切り型のソフトで、この宮舞モカモデルに関しては実際に購入(1万円)してみないと自分の用意したナレーション文での読み上げは試せません。  
今となっては、このモデルを使ったYouTubeチャンネルの動画を見れば良かったのですが、当時はそんなチャンネルも知らなかったので、買うかどうか迷いました。皆さんは私の動画を参考にしてみてください。

もし思ったよりサボルちゃんにあっていない場合1万円が無駄になる。1万円はまあまあデカいぞ…。と思いつつ、もうこれ以上想像通りの音声はなさそうだという予感もあったため、漢気で購入することを決めました。

そして、用意していたセリフを読み上げさせたところ

**もうこれで決まりや…。**

VOICEPEAKのソフトでは感情を指定するパラメータがあり、そういう機能もありつつ、先ほど申し上げた通り、サボルちゃんは感情の起伏が少なめのタイプ。そこで、淡々と聞き取りやすい声で喋ってくれる宮舞モカモデルはどハマりました。

結局のところ、声質が合う合わないはフィーリングで決めることだと思います。たくさん聞き比べていって直感的に何一番合致してそうかを肌で感じる。

ただ、もう少し具体的に言うと、「 **この声で自分のコンテンツを1年間作り続けられるか** 」という問いを自分に投げかけると良いかもしれません。

どんなに客観的に優れた声でも、自分がその声に愛着を持てなかったら、コンテンツ作りが苦痛になってしまいます。逆に、多少技術的には劣っていても、「この声、なんか好きなんだよな」という直感があるなら、それを信じていいと思います。

私の場合、最終的にVOICEPEAKの「宮舞モカ」という声に決めましたが、非常に落ち着いた声で、制作中ずっと聞いていても疲れません。 たまに私のチャンネルでも声に関して言及していただく方もいるのですが、同じような感想を仰っています。

色々機能的な側面から絞り込んでいったら、最後は **直感で締めましょう** 。
