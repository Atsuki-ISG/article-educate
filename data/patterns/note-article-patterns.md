# 参考記事（AIでサボろうチャンネル）から抽出した執筆パターン

抽出元: `articles-example/` 内のnote記事25本
抽出日: 2026-03-27

## タイトルのパターン

| パターン | 例 | 教育記事への応用 |
|---|---|---|
| 問いかけ型 | 「〜する必要はあるのか？」 | 「お子さんの心の癒しって何？」 |
| 課題提示型 | 「〜の壁」「〜はなぜ起きるのか」 | 「子どもが話してくれない、はなぜ起きるのか」 |
| 脱・〇〇型 | 「脱・プロンプト集め」 | 「脱・一方通行の声かけ」 |
| ススメ型 | 「〜のススメ」 | 「『聴く』習慣のススメ」 |
| 体験共有型 | 「〜してみた」「〜している話」 | 「学校で〜に取り組んでいる話」 |

## 冒頭の入り方パターン

### 1. 読者の痛みから入る
読者が「自分のことだ」と感じる具体的な困りごとを提示してから本題へ。
→ 教育記事: 「お子さんに『学校に行きたくない』と言われたこと、ありませんか？」

### 2. 逆説・意外性から入る
「〜と思うかもしれません。でも実は...」で常識を揺さぶる。
→ 教育記事: 「子どもの話を聞くことが大切、とよく言われますが、実は『聞き方』で結果が大きく変わるんです」

### 3. 自分の体験から入る
「私自身も最初は〜でした」で共感と権威性を両立。
→ 教育記事: 「私たちも現場で日々試行錯誤しています」

## 構成の骨格パターン

### パターンA: 課題→原因→解決
1. 課題の提示（読者の共感を得る）
2. なぜそうなるのか（原因の深掘り）
3. どうすればいいか（具体策の提示）
4. まとめ（要点整理 + 励まし）

### パターンB: 仮説→検証→結論
1. よくある思い込みの提示
2. 「一方で」「ただし」で揺さぶる
3. より深い理解の提示
4. 実践への橋渡し

### パターンC: 体験ベース
1. エピソードの紹介
2. そこから得た気づき
3. 一般化した原則
4. 読者への適用提案

## セクション間の接続技法

- 「では、次に」「ここからが本題です」
- 「一方で〜」「ただし〜」で揺さぶり・深掘り
- 「つまり〜」「言い換えると〜」で抽象と具体を行き来
- 前セクションの結論を次の冒頭で軽く拾う

## 読者エンゲージメントの技法

- **直接の問いかけ**: 「こんな経験はないでしょうか？」
- **共感の先出し**: 「めんどくさいと思った方もいるかもしれません」
- **自分の弱さの開示**: 「私自身も反省があります」
- **具体的で小さなCTA**: 「まずは1つだけ試してみてください」（「頑張りましょう」は避ける）

## トーンの特徴（教育記事に活かせるもの）

- **権威ではなく発見の共有**: 「教えてあげる」ではなく「一緒に考える」
- **不確実性への正直さ**: 「正直なところ、明確な答えはありません」
- **段階的な複雑さ**: 簡単な説明→「ただし」→深い理解、の三段構え
- **「完璧でなくていい」の繰り返し**: 読者の心理的安全を確保

## 教育記事特有の応用メモ

- 「仮説→検証」パターンは保護者の「これでいいのかな？」という不安に刺さる
- 「脱・〇〇」型タイトルは、よくある声かけの改善記事に使える
- 「体験ベース」パターンは、学校現場のエピソードと相性がいい
- セクション間の「ただし」は、「この声かけがいつも正解とは限りません」のような深掘りに活用できる
